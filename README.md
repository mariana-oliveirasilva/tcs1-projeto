# Projeto InkCircle

Plataforma social de avaliação de livros e mangás

## Descrição da aplicação
O InkCircle é uma aplicação onde o usuário se cadastra, cria um perfil de
leitor e publica avaliações de livros e mangás (nota de 0 a 5 estrelas +
comentário), podendo encontrar outros usuários com gostos semelhantes.

Projeto desenvolvido para a disciplina de Tecnologia de Construção de
Software I (TCS1).

## Problema que resolve
Voltado para leitores que visam reservar um espaço para suas avaliações pessoais
sobre livros e mangás e descobrir outros leitores com gostos parecidos.
Veja mais detalhes em [`docs/proposta.md`](docs/proposta.md).

## Tecnologias
- **Cliente:** React, JavaScript, HTML, CSS
- **Servidor:** Python, Flask
- **Banco de dados:** SQLite
